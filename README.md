\# C Programming Lab Practicals



This repository contains C programs for basic geometric and mathematical calculations.



\## Programs Included

1\. \*\*Cone Area Calculation (`conearea.c`)\*\*: Calculates the lateral surface area of a cone given its radius and height.

2\. \*\*Square and Cube (`SquareCube.c`)\*\*: Calculates the square and cube of a container side length using macros.
